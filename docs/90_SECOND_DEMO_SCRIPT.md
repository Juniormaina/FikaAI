# FikaAI — 90-second demo script

Spoken + on-screen guide for recording. Keep natural. Do not over-claim.

---

## 0–10 seconds — Problem

**On screen:** FikaAI home (brand + tagline visible).

**Say:**

> “Imagine needing a specialist in Nairobi, but not knowing whether the facility can actually help you — or whether you need a referral — before you make the trip. And when connectivity drops, that information often disappears.”

---

## 10–25 seconds — AI request

**Action:** Type / paste: `I need a cardiologist in Nairobi.` → **Find care**.

**Say:**

> “FikaAI uses AI to turn natural language into structured healthcare-search intent — specialty, location, and request type.”

**Show:** Intent panel with structured JSON / understood need.

---

## 25–40 seconds — Provider discovery

**Action:** Scroll results; open one facility if needed for close-up.

**Say:**

> “Provider facts come from the synthetic provider dataset — not from the AI inventing hospitals. You can see specialist, availability note, appointment and referral requirements, last-updated time, and a clear demo-data label.”

---

## 40–55 seconds — Start journey

**Action:** **View facility** → **Start healthcare journey**.

**Say:**

> “The patient selects a facility and starts a healthcare journey. Requirements and provider details are saved with the journey.”

**Show:** Journey checklist + connection/sync status.

---

## 55–70 seconds — Offline moment

**Action:** Turn off network (DevTools → Offline, or Wi‑Fi off). Open Journey tab if needed.

**Say:**

> “Now the connection is gone, but the patient's saved journey is still available.”

**Show:** Offline status + offline box + saved facility details. Optionally tap **Save offline note**.

---

## 70–82 seconds — Reconnect

**Action:** Restore network.

**Say:**

> “When connectivity returns, pending actions synchronize.”

**Show:** Connection restored → Synchronizing… → Synced.

---

## 82–90 seconds — Closing

**Action:** Brief branding frame (header with FikaAI). Optional quick feedback tap.

**Say:**

> “FikaAI — healthcare access that works when connectivity doesn't.”
