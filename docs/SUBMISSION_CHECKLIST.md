# Submission checklist

## Required project materials

* [ ] Working prototype
* [ ] Source code (this repository)
* [ ] README (root `README.md`)
* [ ] Presentation ([`HACKATHON_PRESENTATION.md`](HACKATHON_PRESENTATION.md))
* [ ] 90-second demo video (record using [`DEMO_RECORDING_PLAN.md`](DEMO_RECORDING_PLAN.md) / [`90_SECOND_DEMO_SCRIPT.md`](90_SECOND_DEMO_SCRIPT.md))
* [ ] AI/tool disclosure ([`AI_TOOL_DISCLOSURE.md`](AI_TOOL_DISCLOSURE.md))
* [ ] Test evidence ([`TEST_REPORT.md`](TEST_REPORT.md))
* [ ] Responsible AI/data notes (README + PROBLEM.md + presentation slide 7)

## Final verification

* [ ] Repository installs (`npm install`)
* [ ] Application starts (`npm run dev`)
* [ ] Seed works (`npm run seed`)
* [ ] Core journey works (search → facility → journey)
* [ ] Offline journey works (DevTools Offline)
* [ ] Reconnection works (pending → synced)
* [ ] AI works (ModelScope and/or Ollama) **or** fallback confirmed for demo
* [ ] AI fallback works
* [ ] Synthetic data clearly labeled
* [ ] No secrets committed (`.env` absent from git)
* [ ] README is accurate vs actual app
* [ ] Demo script matches actual application
* [ ] Automated tests pass (`npm test` → 40/40)

## Do not claim

* Live verified hospital availability
* Hospital partnerships
* Medical diagnosis capability
* Nationwide production deployment
* Real telecom SMS/USSD delivery
